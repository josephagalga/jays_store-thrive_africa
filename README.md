# Jay's Store — Local Business Landing Page

## Sections

1. **Hero** — business name, headline, introduction, relevant store image, and actions.
2. **Our services / products** — three clear offerings: everyday clothing, footwear, and accessories.
3. **How we work** — visit, explore, and choose.
4. **Recent work / collections** — three example physical-store collections.
5. **Contact us** — labeled name, email, and message fields plus store location, phone, and opening hours.
6. **Footer** — business name, copyright, navigation links, and contact information.

A navigation menu links to the sections on the page.

## JavaScript interaction

The project contains two simple JavaScript interactions:

- **Mobile navigation:** the menu button opens and closes the navigation links on smaller screens.
- **Contact-form validation:** submitting the form checks the name, email, and message fields. Invalid fields receive clear feedback. A valid submission displays a confirmation marked as a demo because no message-delivery service is connected.

## Design research / inspiration

The assignment brief asks for design research and inspiration. The following sources were used as visual-direction references for layout, typography, spacing, and presentation. The final page was designed independently for Jay's Store rather than copied from any reference.

- Refero — https://refero.design/
- Mobbin — https://mobbin.com/
- Dribbble — https://dribbble.com/
- Land-book — https://land-book.com/
- Behance — https://www.behance.net/

**Sections influenced:** hero composition, card-based product presentation, generous spacing, navigation, contact layout, and footer structure.


## Build process

1. Selected a physical clothing/lifestyle store as the local business.
2. Chose Jay's Store as the business name and Navrongo, Ghana as the location.
3. Planned a one-page layout with the six required sections.
4. Created the HTML structure and navigation.
5. Added CSS for the laptop layout, typography, cards, forms, buttons, and visual hierarchy.
6. Added plain JavaScript for mobile navigation and contact-form validation.
7. Added mobile media queries as the bonus work.
8. Added this README documentation.
9. Tested the navigation, form interaction, and responsive layout in a browser.
